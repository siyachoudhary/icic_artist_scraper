Error fixes:

#1 On mac, if pop up says chrome driver cannot be opened:
- Click "Cancel" on the warning.
- Go to System Settings > Privacy & Security.
- Scroll down to Security section.
- You’ll see something like: "chromedriver was blocked from use because it is not from an identified developer."
- Click “Allow Anyway”.
- Run your script again — this time you'll get a new dialog with “Open” as an option.
